# RAM Process

## Purpose

This folder contains the company-wide RAM framework that defines how RAM activities shall be planned, executed, reviewed, approved, and controlled across all projects.

The RAM Process establishes a common approach for Reliability, Availability, Maintainability and Life Cycle Cost activities and ensures consistency across the organization.

This folder is considered the authoritative source for RAM governance, procedures, methods and responsibilities.

---

## Scope

The RAM Process applies to:

- All RAM engineering activities
- All RAM deliverables
- All RAM reviews
- All RAM plans
- FMEA and FMECA activities
- FRACAS activities
- Reliability prediction activities
- RAM compliance activities
- Life Cycle Cost activities

## Usage

When RAM activities are performed, the applicable process documents in this folder shall be considered the primary reference.

Where project-specific approaches differ from the standard process, deviations shall be formally documented and approved.
