# Knowledge

## Purpose

This folder contains reusable RAM knowledge, engineering references, lessons learned, best practices, and technical guidance that can be applied across multiple railway projects.

The content in this folder is project-independent and serves as a centralized knowledge base for RAM, FMEA, FRACAS, reliability prediction, maintainability, availability, and lifecycle cost activities.

## Rules

- Store project-specific information under the Projects folder.
- Store reusable engineering knowledge in the Knowledge folder.
- Keep technical guidance generic and reusable.
- Update lessons learned after major reviews, bids, incidents, and customer feedback.
- Reference source documents whenever possible.
